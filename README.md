# Ceping202610

V2.11 个人测评系统的可自部署服务端源码。完整项目位于 [`assessment-server/`](assessment-server/)。

## 使用

先阅读 [部署、备份与安全说明](assessment-server/README.md)。需要 Node.js 24.15+（限 Node 24 系列）、Python 3 和 ReportLab；Dockerfile 已包含 Python 依赖，也提供 Linux Docker Compose 示例。

```sh
cd assessment-server
cp .env.example .env
# 先按项目说明安装 Python 3 + ReportLab，并自行生成填写 AUTH_SECRET
npm ci
npm start
```

生产环境请先配置真实域名、HTTPS、随机认证密钥及数据库备份。只将 `public/` 作为前端静态资源；通过 Node 服务运行整个应用。

## 公开源码与数据边界

本仓库为公开源码，包含后端计分实现与题库，任何人都可查看或下载。部署后将这些文件留在服务端，只能避免浏览器直接取得实现，不能使已公开的源码保密。

仓库不包含真实账号、真人答卷、运行数据库、日志、部署凭据或生产密钥。请勿提交 `.env`、数据目录内容或备份。

参照来自合成模拟与语义复核，不是经真实人群验证的常模。结果仅供个人探索，不构成诊断、招聘淘汰或资格判断依据。详见项目说明中的使用边界。
