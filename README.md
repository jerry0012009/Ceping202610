# Ceping202610

V2.9 个人测评系统的可自部署服务端源码。完整项目位于 [`assessment-server/`](assessment-server/)。

## 使用

先阅读 [部署、备份与安全说明](assessment-server/README.md)。需要 Node.js 24.15+（限 Node 24 系列），也提供 Linux Docker Compose 示例。

```sh
cd assessment-server
cp .env.example .env
# 自行生成并填写 AUTH_SECRET，再安装依赖和启动
npm ci
npm start
```

生产环境请先配置真实域名、HTTPS、随机认证密钥及数据库备份。只将 `public/` 作为前端静态资源；通过 Node 服务运行整个应用。

## 当前内容

- 邮箱注册、登录、逐页保存与历史报告
- 服务端计分、账号数据隔离、唯一只读管理员
- V2.9 题目与分维度算法；建筑工地外派管理岗的职业性格组合模型
- `2.9-report-4` 报告解释文案；数值算法、权重、校准和参照区间保持不变
- 自动化测试及明确标注的合成作答样本

在项目目录运行 `npm test` 验证。所有测试账号和答卷均为合成测试数据，不是真实受测者记录。

## 公开源码与数据边界

本仓库为公开源码，包含后端计分实现与题库，任何人都可查看或下载。部署后将这些文件留在服务端，只能避免浏览器直接取得实现，不能使已公开的源码保密。

仓库不包含真实账号、真人答卷、运行数据库、日志、部署凭据或生产密钥。请勿提交 `.env`、数据目录内容或备份。

参照来自合成模拟，不是经真实人群验证的常模；结果仅供个人探索，不构成诊断或招聘、淘汰依据。详见项目说明中的使用边界。
